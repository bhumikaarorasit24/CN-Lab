# Experiment 6 – DNS Packet Analysis (Windows)

## Aim
Analysis of Application Layer packets (DNS) using DNS commands and Wireshark on Windows.

## Objective
- Understand the working of DNS as an application layer protocol.
- Analyze DNS packets generated by DNS commands.
- Capture and study DNS packets using Wireshark on Windows.

## Tools Required
- Windows PC with Internet access
- Command Prompt (cmd)
- Wireshark (https://www.wireshark.org/)

## Procedure

### Part A: DNS commands (nslookup)
1. Open Command Prompt (`Win + R` → `cmd`).
2. Find the IP address of a domain:
   ```
   nslookup www.google.com
   ```
   Observe the DNS server used and the resolved IP addresses.
3. Reverse lookup (IP → domain):
   ```
   nslookup 142.251.155.119
   ```
4. Query a different record type (mail servers):
   ```
   nslookup -query=mx google.com
   ```

### Part B: DNS packet analysis with Wireshark
1. Open Wireshark as Administrator and select the active interface (Wi-Fi/Ethernet).
2. Click the blue shark-fin icon to start capture.
3. In Command Prompt run `nslookup www.google.com`.
4. Click the red square to stop capture.
5. Apply the display filter: `dns`
6. Select the DNS query packet (UDP port 53) and expand: **Transaction ID**, **Flags**, **Questions**.
7. Select the DNS response packet and check the **Answers** section for the resolved IP address.
